# 🌭 La Esquinita - Comida Rápida al Paso

> Sitio web de **La Esquinita**, local de comida rápida en Renca, Santiago de Chile.

## 🚀 Instalación

```bash
cd ESQUINITA
npx live-server --port=3000 --open=index.html
```

## 📁 Estructura

```
ESQUINITA/
├── components/     → nav.html, footer.html
├── css/            → style.css
├── js/             → app.js, carrito.js, whatsapp.js
├── pages/          → menu.html, carrito.html, contacto.html
├── assets/         → img/, icons/
├── index.html
├── package.json
└── README.md
```

## 🛠 Stack
HTML5 | CSS3 | JavaScript ES6+ | Bootstrap 5.3 | Bootstrap Icons | Google Fonts
